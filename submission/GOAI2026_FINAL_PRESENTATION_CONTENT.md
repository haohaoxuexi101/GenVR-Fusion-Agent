### 页面研究问题

> 能否让 Agent 在固定材料预算下自主决定“生成什么、计算什么、何时升级精算、何时承认证据不足”？

### 口播稿

> 这是一个真实的组合搜索问题。固定中心源和 11 个吸收块后，仍有约 225 亿种合法排布。Monte Carlo 适合精确验证，却不适合穷举；单靠人工又难以系统利用每次计算得到的完整物理场。因此我们的目标不是做一个聊天机器人，而是让 Agent 管理科学实验预算，决定下一次最有价值的计算。

### 左栏：运行前冻结

- `7×7` 宏网格与中心源
- 材料种类与 11 个吸收块总量
- 远场绝对通量目标

### 中栏：Agent 可以决策

- 选择父代结构
- 调整物理算子权重和重点泄漏方向
- 决定探索/利用比例
- 选择 GMC 筛选批次

### 右栏：Agent 不能做

- 不能直接填写材料坐标
- 不能增加材料或移动源
- 不能修改目标函数
- 不能修改验证阈值
- 不能批准自己的成功声明

### 页面底句

**语言模型负责科学决策；确定性编译器、GMC、MC 和 Verifier 负责事实。**

### 口播稿

> 我们把环境分为三部分。科学目标、材料预算和验证门槛在运行前冻结；Agent 只负责父代、策略、批次、晋级和停止等高层决策；具体几何由约束编译器生成，数值由 GMC 和 MC 计算，最终结论由独立 Verifier 判断。这避免了模型修改规则来迎合结果。

### 对应评分

- 环境与探索机制原创性

## 第 5 页｜核心创新：不是把现成模块串起来

**建议时间：2:25–3:10，共 45 秒**

### 页面标题

**三个实质创新**

### 创新 1｜同一个 GMC 场承担双重角色

**结构筛选证据 + Monte Carlo 权窗引导**

- 避免“快速近似模型”和“精细验证模型”之间完全割裂。

### 创新 2｜物理场真正改变下一代结构

**不是一次性生成，而是证据反馈再生成**

- 从 GMC 高通量、远场路径连续性和最严重泄漏扇区提取重要性。
- 将低价值位置的吸收块迁移到高重要性路径，同时保持材料总量不变。

### 创新 3｜Agent 无权认证自己

**独立 Verifier 用冻结门槛否决过早结论**

- 强候选信号不等于已验证发现。
- 失败结果、拒绝记录和预算耗尽全部进入证据链。

### 页面底句

> 智能不只体现在找到好方案，也体现在知道什么时候不能宣布成功。

### 口播稿

> 我们的差异不只是调用了几个工具。第一，同一个 GMC 场既用于候选筛选，也直接生成候选专属权窗。第二，场信息会改变父代和下一代结构，而不是预先写死顺序。第三，系统把“提出结论”和“批准结论”拆开，独立 Verifier 可以否决 Agent。这使它更接近一个可审计的科研过程。

### 对应评分

- 环境与探索机制原创性 15 分
- 相对已有研究范式的实质推进 10 分

## 第 9 页｜精细验证：GMC 权窗如何服务 MC

**建议时间：6:00–7:05，共 65 秒**

### 页面标题

**GMC 不替代 MC：它把计算资源送到最难采样的区域**

### 页面方法

```text
候选专属 GMC 通量场
→ 平滑与低分位截断
→ importance(x) ∝ phi_GMC(x)^(-0.9)
→ 12 级权窗
→ 分裂 / 俄罗斯轮盘赌
→ Analog MC 与权窗 MC 同设计一致性检查
```

### MC 配置

- `56×56` 网格
- 4 个独立重复
- 每个设计、每种方法共 20,000 根历史
- 总 MC 根历史：80,000

### 主要统计信号

- 远场候选/基准：**0.10999**
- 估计下降：**89.00%**
- 差异：**z = -50.80**
- 候选 95% 上界低于基准 95% 下界

### 权窗精度作用

- 基准逐格中位相对误差：`0.541 → 0.0576`，约 **9.39×**
- 候选逐格中位相对误差：`0.628 → 0.0874`，约 **7.19×**

### 建议视觉

- 使用 `outputs/gmc_material_discovery/run_20260920_020815/mc_certification.png`。
- 若版面拥挤，可只保留四张通量图、区域置信区间图和一致性 z 图。

### 口播稿

> GMC 的第二个作用是生成候选专属权窗。低 GMC 通量区被赋予更高重要性，通过分裂和轮盘赌把更多统计样本送到深穿透区域。最终我们在 56×56 网格上做了四个独立重复。权窗 MC 给出远场候选/基准 0.10999，约 89% 的下降信号，并显著降低逐格相对误差。但权窗只提高效率，结构好坏仍由绝对通量和一致性门槛决定。

### 对应评分

# 高频答辩问题与一句话回答

## 1. 这个综合指标是不是你们自己构造的？

是。它是运行前冻结的 GMC 筛选标量，用于有限预算下排序，不被当作通用标准；最终屏蔽结论由 MC 绝对通量、置信区间和一致性门槛决定。

## 2. 如何证明 API 真正在参与，而不是写死流程？

封版轨迹包含 17 个唯一 API `response_id`、完整请求/响应、12 步工具选择及其参数；关闭 API 或缺少密钥会失败，系统没有确定性策略回退。

## 3. Agent 能直接设计几何吗？

不能。Agent 只能选择父代、物理算子权重、扇区和探索比例；约束编译器生成一进一出的合法等质量结构。

## 4. 为什么 89% 下降仍然是 inconclusive？

因为冻结的同设计 Analog/权窗一致性门槛要求两者均满足 `|z|≤2`，基准得到 `z=-2.1477`；强信号不能覆盖失败门槛。

## 5. 权窗会不会让结果有偏？

分裂和俄罗斯轮盘赌按粒子权重守恒设计，但有限样本仍需同设计 Analog/权窗一致性检查；本次正因为该检查未完全通过，所以没有宣布认证成功。

## 6. 你们的“物理引导”是什么？

从 GMC 全场中提取通量、源距离、邻域路径连续性和角向泄漏，优先把低价值吸收块迁移到高重要性泄漏路径，而不是随机洗牌。

## 7. 为什么不用中子扩散模型？

本次主动冻结为 `gmc_only`，减少方法混杂，让 GMC 同时承担发现反馈和 MC 权窗引导，更容易验证闭环中每个结论的来源。

## 8. 当前成果可以用于真实工程吗？

不能直接外推。当前证明的是二维冻结 benchmark 内的自主发现与验证机制；进入工程应用前还需要多群、三维、真实核数据、制造约束和外部程序交叉验证。
