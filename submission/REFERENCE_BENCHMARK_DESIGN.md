# GenShield-Agent Reference Benchmark 设计

当前口径日期：2026-09-20。本文只描述 `gmc_only` 正式主线，不再使用旧射线效应消融作为本次发现的 Reference Benchmark。

## 1. 参照目的

参照系用于回答两个问题：

1. Agent 发现的材料排布是否优于固定原始结构，而不是只得到一个没有对照的低通量场；
2. GMC 权窗 MC 是否与同一结构的 Analog MC 在统计误差内一致，而不是用有偏人口控制制造虚假改进。

## 2. 固定基准结构

- 基准签名：`ded6840cea70`
- 宏网格：`7×7`
- 中心体源：`(3,3)`
- 强吸收块数量：11
- 基准 GMC 综合风险：定义为 `1.0`
- 材料参数与候选完全相同，候选只允许一进一出的等质量位置交换。

基准吸收块为：

```text
(1,1), (1,3), (1,5), (2,2), (2,4),
(3,1), (3,5), (4,2), (4,4), (5,1), (5,5)
```

## 3. 三层参照

### 3.1 平凡参照：保持基准不变

所有 GMC 指标均先除以基准对应指标。`GMC risk < 1` 只表示候选在项目定义的综合风险下优于固定基准；它不是最终物理认证。

### 3.2 搜索参照：完整候选分布

正式运行生成 59 个合法非基准结构，并实际用 GMC 筛选 16 个。筛选风险覆盖 `0.07593` 至 `1.09295`，既包含明显改善，也包含劣于基准的负结果。报告保留全部 16 个候选的顺序、几何、GMC 场和风险，不只保留冠军。

本次正式轨迹生成了 9 个 `random_explore` 结构，但 Agent 没有选择它们消耗有限 GMC 预算，因此当前不能报告“随机搜索成功率”。它们只用于保证候选池存在探索分支，不能冒充完成的随机对照实验。

### 3.3 方法参照：Analog MC 对权窗 MC

基准和最终候选分别运行：

- 20,000 根历史 Analog MC；
- 20,000 根历史 GMC 权窗 MC；
- 每种方法 4 个独立重复；
- 相同 `56×56` 网格和相同区域定义。

权窗只能提高统计效率，不能改变无偏期望。Verifier 要求基准和候选的 Analog/权窗远场差异都满足 `abs(z)≤2.0`。

## 4. 正式结果

| 对照 | 结果 | 判定 |
|---|---:|---|
| 最佳 GMC 候选风险 / 基准 | 0.07593 / 1.0 | GMC 筛选通过 |
| 权窗 MC 远场候选/基准 | 0.109986 | 改进信号通过 |
| 远场差异 z | -50.802 | 显著性通过 |
| 候选 Analog/权窗一致性 z | 0.8238 | 通过 |
| 基准 Analog/权窗一致性 z | -2.1477 | **失败** |
| 最终声明 | `inconclusive` | Verifier 接受 |

该结果说明候选相对固定基准存在强下降信号，但最终方法一致性参照没有全部通过，因此不能把候选升级为已认证发现。

## 6. 当前不足

本次只完成一条正式自治轨迹，尚未执行“多个 Agent seed 下，随机策略与物理反馈策略使用相同 GMC 预算”的配对实验。因此当前 Reference Benchmark 足以验证基准改进和 MC 方法一致性，但不足以声称 Agent 在统计意义上稳定优于随机搜索。
